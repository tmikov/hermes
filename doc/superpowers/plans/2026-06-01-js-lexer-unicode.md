# JS Lexer — Unicode Character Properties (subsystem ④) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the Unicode character-property predicates the lexer needs (`isUnicodeIDStart`/`IDContinue`, `isUnicodeOnlySpace`, and the supporting category predicates) to a zero-`unsafe` `unicode` crate, with range tables generated **from the same `lib/Platform/Unicode/UnicodeData.inc`** the C++ uses, so they are byte-identical and pinned to Hermes's Unicode version (17.0.0).

**Architecture:** A new `unicode` crate. A committed dev script `gen_tables.py` parses the 8 ID/letter/space range tables out of `lib/Platform/Unicode/UnicodeData.inc` and emits `src/tables.rs` (each table a sorted `[(u32, u32); N]` of inclusive ranges). `src/lib.rs` ports `CharacterProperties.{h,cpp}`: the inline ASCII/surrogate helpers + constants, the binary-search `lookup`, and the table-backed predicates. The RegExp canonicalization / property-escape machinery in `CharacterProperties.cpp` is **excluded** (it belongs to the future RegExp component, not the lexer).

**Tech Stack:** Rust (edition 2021), std only, `unsafe_code = "forbid"` (pure data + binary search). Python 3 for the one-off table generator.

**Reference spec:** `doc/superpowers/specs/2026-06-01-js-lexer-design.md` (decision: port the generated tables, pin the Unicode version, do NOT use a Rust unicode crate).
**C++ source of truth:**
- `include/hermes/Platform/Unicode/CharacterProperties.h` — constants + inline helpers + the table-predicate declarations.
- `lib/Platform/Unicode/CharacterProperties.cpp` — `UnicodeRangeComp`/`lookup` and the predicate bodies (lines 22–146). EXCLUDE the canonicalize/regexp code (lines 148+).
- `lib/Platform/Unicode/UnicodeData.inc` — the range tables (read its header for the version note; arrays at the line numbers below).

**Porting rule:** keep structure close to the C++ and copy the comments. The tables are generated, not hand-typed, so they cannot drift from the C++ data; the count assertions guard the generator.

**Do NOT** `cd` out of the project root.

## The 8 tables (anchors for the generator + tests)

In `lib/Platform/Unicode/UnicodeData.inc`, two declaration forms appear:
- C-array: `static constexpr UnicodeRange NAME[] = { {0x.., 0x..}, ... };`
- std::array: `static constexpr std::array<UnicodeRange, N> NAME = {{ {0x.., 0x..}, ... }};`

| Table | Form | Range count |
|-------|------|-------------|
| `UNICODE_LETTERS` | C-array | 378 |
| `UNICODE_COMBINING_MARK` | C-array | 266 |
| `UNICODE_DIGIT` | C-array | 69 |
| `UNICODE_CONNECTOR_PUNCTUATION` | C-array | 6 |
| `UNICODE_OTHER_ID_START` | std::array | 4 |
| `UNICODE_OTHER_ID_CONTINUE` | std::array | 7 |
| `UNICODE_PATTERN_LETTER` | std::array | 1 |
| `UNICODE_PATTERN_CONTINUE` | std::array | 0 |

Each `UnicodeRange{first, second}` is an **inclusive** `[first, second]` range; the tables are sorted ascending and non-overlapping (required for binary search).

- [ ] **Step 1: Write the generator** `rust/crates/unicode/gen_tables.py`:

```python
#!/usr/bin/env python3
# Copyright (c) Meta Platforms, Inc. and affiliates.
#
# This source code is licensed under the MIT license found in the
# LICENSE file in the root directory of this source tree.
#
# Generate rust/crates/unicode/src/tables.rs from
# lib/Platform/Unicode/UnicodeData.inc. The tables are the ID/letter/space range
# tables the JS lexer needs. Re-run when the Unicode data is updated:
#   python3 rust/crates/unicode/gen_tables.py
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[3]
INC = ROOT / "lib/Platform/Unicode/UnicodeData.inc"
OUT = Path(__file__).resolve().parent / "src/tables.rs"

# table name -> expected range count (anti-drift guard)
EXPECTED = {
    "UNICODE_LETTERS": 378,
    "UNICODE_COMBINING_MARK": 266,
    "UNICODE_DIGIT": 69,
    "UNICODE_CONNECTOR_PUNCTUATION": 6,
    "UNICODE_OTHER_ID_START": 4,
    "UNICODE_OTHER_ID_CONTINUE": 7,
    "UNICODE_PATTERN_LETTER": 1,
    "UNICODE_PATTERN_CONTINUE": 0,
}

PAIR = re.compile(r"\{\s*(0x[0-9a-fA-F]+|\d+)\s*,\s*(0x[0-9a-fA-F]+|\d+)\s*\}")

def extract(src, name):
    # Try the C-array form, then the std::array form.
    m = re.search(r"UnicodeRange\s+" + name + r"\s*\[\]\s*=\s*\{(.*?)\};", src, re.S)
    if not m:
        m = re.search(
            r"std::array<\s*UnicodeRange\s*,\s*\d+\s*>\s+" + name + r"\s*=\s*\{\{(.*?)\}\};",
            src, re.S)
    if not m:
        sys.exit(f"error: table {name} not found in {INC}")
    pairs = [(int(a, 0), int(b, 0)) for a, b in PAIR.findall(m.group(1))]
    return pairs

def main():
    src = INC.read_text()
    # Pull the Unicode version line from the .inc header for provenance.
    ver = re.search(r"for Unicode version ([0-9.]+)", src)
    version = ver.group(1) if ver else "unknown"
    out = []
    out.append("// Copyright (c) Meta Platforms, Inc. and affiliates.")
    out.append("//")
    out.append("// This source code is licensed under the MIT license found in the")
    out.append("// LICENSE file in the root directory of this source tree.")
    out.append("//")
    out.append(f"// GENERATED by gen_tables.py from lib/Platform/Unicode/UnicodeData.inc")
    out.append(f"// Unicode version {version}. DO NOT EDIT BY HAND.")
    out.append("//")
    out.append("// Each entry is an inclusive [first, last] code-point range; tables are")
    out.append("// sorted ascending and non-overlapping (required for binary search).")
    out.append("")
    for name, expected in EXPECTED.items():
        pairs = extract(src, name)
        if len(pairs) != expected:
            sys.exit(f"error: {name} has {len(pairs)} ranges, expected {expected}")
        # Sanity: sorted and non-overlapping.
        for i in range(1, len(pairs)):
            if pairs[i][0] <= pairs[i - 1][1]:
                sys.exit(f"error: {name} not sorted/non-overlapping at index {i}")
        out.append(f"pub static {name}: [(u32, u32); {len(pairs)}] = [")
        for a, b in pairs:
            out.append(f"    (0x{a:04x}, 0x{b:04x}),")
        out.append("];")
        out.append("")
    OUT.write_text("\n".join(out))
    print(f"wrote {OUT} (Unicode {version})")

if __name__ == "__main__":
    main()
```

use std::cmp::Ordering;

/// Binary-search `table` (sorted, non-overlapping inclusive ranges) for `cp`.
fn lookup(table: &[(u32, u32)], cp: u32) -> bool {
    table
        .binary_search_by(|&(first, last)| {
            if last < cp {
                Ordering::Less
            } else if cp < first {
                Ordering::Greater
            } else {
                Ordering::Equal
            }
        })
        .is_ok()
}
