SH.cpp emits __attribute__((constructor)) to run _sh_wasm_register_unit for a natively compiled Wasm unit's self-registration (task 4 of the wasm native-backend plan). MSVC has no equivalent attribute; the standard substitute is the ".CRT$XCU" section trick (#pragma section(".CRT$XCU", read) + __declspec(allocate(".CRT$XCU"))). Generated C currently emits #error under _MSC_VER instead of implementing it, since it could not be verified against a real MSVC toolchain in this environment. Implement and verify the CRT$XCU form, or otherwise unblock MSVC support for Wasm self-registration. See lib/BCGen/SH/SH.cpp, the block referencing 's_wasm_reg_ctor', tag wasm-msvc-ctor.
