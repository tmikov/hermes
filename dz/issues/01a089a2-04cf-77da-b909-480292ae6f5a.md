`WasmIRGen::onTableFill` passes `tableIsFuncRefLiteral(tableIndex)` to the
`wasmTableFill` builtin, and the builtin reads it (arg 6) and hands it to
`setWasmTableSlot`, so filling an externref table with an arbitrary JS value
is implemented. Nothing exercises it.

Found while proving Task 11's tests non-vacuous: a deliberate break that
replaced that argument with a hardcoded literal 1 -- which would make
`table.fill` on an externref table raise a TypeError for any non-null value --
left the whole suite green. `test/wasm/e2e-bulk-table.wat` covers `table.fill`
only on a funcref table.

`table.init` on an externref table is now covered, by
`test/wasm/e2e-elem-passive-items.wat`; `table.fill` is the remaining one of
the pair. A test would need an externref table, a `table.fill` with a value
that is not a function, and a `table.get` reading a filled slot back by
identity.
