Found 2026-09-13 while making module-defined tags real WebAssembly.Tag cells.
Pre-existing and unrelated to that change.

Every WebAssembly class sets @@toStringTag to its bare name:

  Hermes:  [object Tag]        [object Memory]
  node 24: [object WebAssembly.Tag]   [object WebAssembly.Memory]

The JS API spec gives these the qualified name. Measured on both for Tag and
Memory; the other classes are set the same way, in createWebAssemblyObject.

Trivial to fix -- each site passes runtime.getPredefinedStringHandle(a bare
Predefined:: name) and wants a qualified string instead -- but it is a
user-visible string, so anything asserting the current spelling has to move
with it. test/wasm/e2e-tag-export.wat pins the current value and points here.
